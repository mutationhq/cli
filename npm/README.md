# The npm packages

`mutation` is published to npm as five packages, all at the same version:

| Package | Holds |
| --- | --- |
| `@mutationhq/cli` | The launcher `bin/mutation.mjs`, installed as the `mutation` command, and the four packages below as `optionalDependencies` at its exact version |
| `@mutationhq/cli-darwin-arm64` | `bin/mutation` for macOS ARM64 |
| `@mutationhq/cli-linux-x64` | `bin/mutation` for Linux x64, glibc 2.28 or newer |
| `@mutationhq/cli-linux-arm64` | `bin/mutation` for Linux ARM64, glibc 2.28 or newer |
| `@mutationhq/cli-win32-x64` | `bin/mutation.exe` for Windows x64 |

## How an install works

1. npm installs `@mutationhq/cli` and reads its optional dependencies.
2. Each platform package declares `os`, `cpu` and, on Linux, `libc: ["glibc"]`, so npm (and pnpm, Yarn, Bun) installs only the one that matches the machine and skips the others. No install script runs.
3. `mutation` runs the launcher, which finds the matching package with Node's `require.resolve`, starts its binary with the same arguments and stdio, forwards SIGINT and SIGTERM, and exits with the binary's exit code. If the binary was ended by a signal, the launcher raises that signal on itself, so the shell sees what it would have seen without Node in between.
4. When no package matches (an unsupported system, musl, or optional dependencies omitted), the launcher names the supported platforms and exits 1.

`preferUnplugged: true` tells Yarn Plug'n'Play to keep each binary on disk where it can be executed.

## What the release adds

The binaries are not in git (`npm/*/bin/` is ignored, except the launcher's folder). The release command builds each one natively on its platform, signs it, copies it into its package's `bin/`, writes `THIRD-PARTY-NOTICES` at the package root (cargo-about for the crates, then the Rust standard library, Linguist, jemalloc, libdeflate and the MPL-2.0 source statement, as the [changelog](../CHANGELOG.md) lists), writes the version into all five manifests, and publishes the four platform packages before `@mutationhq/cli`.
