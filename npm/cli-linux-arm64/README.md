# @mutationhq/cli-linux-arm64

The mutation binary for Linux ARM64 (glibc 2.28 or newer). Install [`@mutationhq/cli`](https://www.npmjs.com/package/@mutationhq/cli) instead: it depends on this package and runs its binary.
